# 자막 편집기 v4

쇼츠 자막 타임라인 편집기 — https://ssggg0.github.io/shorts-editor/

- `index.html` — 편집기 본체(단일 파일, 영상은 `clip.mp4`로 분리 서빙)
- `clip.mp4` — 540×960 / H.264 High / AAC 80k / **0.5초마다 키프레임(-g 15)** / `+faststart` 미리보기 영상 7.5MB (33.33초)

## v4에서 고친 것 (아이폰 Safari 실기기 피드백)

- **iOS 시킹 먹통**: `clip.mp4`를 키프레임 0.5초 간격(`-g 15 -keyint_min 15 -sc_threshold 0`)으로 재인코딩. 0.1초 단위로 뒤로 돌려도 프레임이 바로 뜬다.
- **실시간 타임 바**: `requestAnimationFrame` + `setInterval(60ms)` 보조 루프로 `0.00s` 시간, 스크러버, 플레이헤드, 파형 진행색, 자막 오버레이가 항상 따라 움직인다.
- **손가락 시킹**: 시간 표시 바로 아래 전체 구간 스크러버(`input[type=range]`, step 0.05) 추가. 눈금자·썸네일/파형·트랙 빈칸 탭도 해당 초로 이동. `seeking`/`seeked` 상태를 관리해 시킹 중 타이머가 이전 시간으로 튀지 않는다.
- **자막 추가 직관화**: 선택 시 `[적용] + [＋ 새 자막] + [✂️] + [🗑]`, 빈 구간에서는 `[＋ 현재 위치(0.00s)에 자막 추가]`가 항상 눌린다(빈 입력이어도 자막이 생기고 바로 편집 상태).
- **영상 미니 컨트롤**: 영상 아래 `−3초 / 재생·정지 / +3초`, `playsinline` 유지로 iOS 기본 컨트롤이 끼어들지 않는다.
- **참외 요청**: "웹페이지에서는 바로 전송이 안 돼서, 복사 후 채팅에 붙여넣거나 ↗ 공유로 보내주세요" 안내 1줄.
- **영상 저장/공유**: `내보내기`·`···` 시트에 `[📥 영상 저장/공유]` — iOS 공유 시트의 '비디오 저장'으로 사진 앱에 저장, 안 되면 새 탭에서 길게 눌러 저장.

## 기능(누적)

- **경량 로딩**: 단일 HTML(약 110KB) + `clip.mp4`(`preload="auto"`).
- **3단 타임라인**: 눈금자·플레이헤드 / 비디오 썸네일 스트립 + 오디오 파형(Web Audio `decodeAudioData`) / 자막 구간 트랙.
- **편집**: 구간 드래그 이동·양끝 핸들 길이 조절, 재생헤드 분할(✂️), 되돌리기(··· → 실행 취소), 0.5×·1.5× 배속, 1×·2×·4× 줌(핀치 지원).
- **스타일**: 상단 제목 편집, 자막 스타일(흰 박스 / 다크 바 / 외곽선), 자막 높이 슬라이더 — 영상 위에서 실시간 비교.
- **참외 요청**: 요청 + 상단 제목 + 스타일 + 높이 + 전체 타임코드를 한 번에 복사/공유.
- 다른 영상(mp4·mov) 교체, 자막 파일(JSON·SRT·TXT) 불러오기, 내보내기(텍스트·JSON·SRT), 편집 내용 자동 저장(localStorage).
